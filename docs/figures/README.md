# Editable BARR pair-fusion diagrams

The layout follows the existing C05 documentation style. The algorithm here is frozen BARR candidate B.

Blue marks the analytical pair scout, its certificates, and archive/state feedback. Orange marks structured expansion and recovery. Remaining operations use black text and borders on white or transparent backgrounds. Algorithm numbers connect the main controller to the two detailed panels. All main-search operations are serial. R denotes the next population iteration.

The draw.io sources contain editable native shapes and connectors. PDFs, SVGs and PNGs were exported with draw.io Desktop. The PDFs and SVGs embed the editable diagram; the PNGs are previews. See [figure-manifest.json](figure-manifest.json) for file hashes. Mathematical model and three algorithms: [PDF](../barr_model_algorithm.pdf), [LaTeX](../barr_model_algorithm.tex).
